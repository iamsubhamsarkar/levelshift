## BUILD_STEP
goal: Read this before you start building.
why: The concepts in these build phases are stable and faithful to the Phase 9 theory. But the exact API calls, library names, model IDs, and endpoints move fast.
verify: Understand this: treat the specific API calls and model names in these steps as things to verify against the current provider docs (Groq, NVIDIA NIM) and library docs when you actually build. The build steps are grounded in the theory plus standard Groq/NIM + Python tooling; the CONCEPTS are what endure, while the exact syntax and model IDs change over time. If a call fails or a model name is rejected, check the provider's current docs first — that is normal, not a mistake in your work.
reference: Phase 9, Ch 3 (providers change) and Ch 12 (frameworks churn)

## BUILD_STEP
goal: Confirm you have Python 3.10+ installed.
why: Every agent tool and library we use is Python-first. (Learned in Phase 9, Ch 2-3.)
windows:
```
python --version
```
ubuntu:
```
python3 --version
```
verify: You see "Python 3.10" or higher. If the command isn't found, install Python from python.org (Windows) or run: sudo apt update && sudo apt install python3 python3-venv (Ubuntu 24.04).
troubleshoot: On Windows, if `python` opens the Microsoft Store, use `py --version` instead, or install from python.org and re-open your terminal.
reference: Phase 9, Ch 2

## BUILD_STEP

why: One isolated folder keeps this whole build (ATLAS) self-contained.
windows:

```
mkdir agentic-ai-lab
cd agentic-ai-lab
```
ubuntu:
```
mkdir agentic-ai-lab
cd agentic-ai-lab
```
verify: Your terminal's current directory is now agentic-ai-lab.
reference: Phase 9, Ch 2

## BUILD_STEP
goal: Create and activate a Python virtual environment (venv).
why: A venv isolates this project's dependencies so they never collide with other projects — the universal 2026 baseline. (Learned in Phase 9, Ch 3.)
windows:
```
python -m venv .venv
.venv\Scripts\Activate.ps1
```
ubuntu:
```
python3 -m venv .venv
source .venv/bin/activate
```
verify: Your terminal prompt now shows (.venv) at the start of the line.
troubleshoot: If activation is blocked on Windows PowerShell, run: Set-ExecutionPolicy -Scope Process RemoteSigned  — then try the activate command again.
reference: Phase 9, Ch 3

## BUILD_STEP
goal: Install the two libraries we'll start with.
why: The openai library speaks the OpenAI-compatible protocol used by Groq AND NVIDIA NIM, so one client talks to both. python-dotenv loads your secret keys safely.
windows:
```
pip install openai python-dotenv
```
ubuntu:
```
pip install openai python-dotenv
```
verify: The install finishes without errors. Run `pip list` and you see openai and python-dotenv listed.
troubleshoot: If a corporate network blocks the default index, add: --index-url https://pypi.org/simple
reference: Phase 9, Ch 3

## BUILD_STEP
goal: Get a free Groq API key and note a current model name.
why: Groq serves strong open models very fast — ideal for the many quick calls inside an agent loop. (Learned in Phase 9, Ch 2-3.)
verify: You have signed up at console.groq.com, created an API key (it starts with gsk_), and copied a current model name from their model list. Keep the key private — treat it like a password.
troubleshoot: If you'd rather use NVIDIA NIM as your provider, sign up at build.nvidia.com instead and copy that key + its OpenAI-compatible base URL. The rest of the build works the same because both speak the same protocol.
reference: Phase 9, Ch 3

## BUILD_STEP
goal: Store your key safely in a .env file (never in code).
why: Secrets in code get leaked. A .env file, ignored by git, keeps them out of your source. (Learned in Phase 9, Ch 3.)
code:
```
GROQ_API_KEY=gsk_your_real_key_here
GROQ_BASE_URL=https://api.groq.com/openai/v1
GROQ_MODEL=llama-3.3-70b-versatile
```
windows:
```
notepad .env
```
ubuntu:
```
nano .env
```
verify: A file named .env exists in agentic-ai-lab and contains your real key. Also create a .gitignore containing a line ".env" so it is never committed.
troubleshoot: Make sure the file is exactly ".env" (no .txt). On Windows, in Notepad's Save dialog set "Save as type" to "All Files".
reference: Phase 9, Ch 3
