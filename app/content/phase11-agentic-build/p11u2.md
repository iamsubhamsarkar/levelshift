## BUILD_STEP
goal: Write an embed() helper that turns text into a vector.
why: This is the single new primitive of the chapter: text in, a list of numbers out, where closeness of numbers means closeness of meaning. (Learned in Phase 9, Ch 10, section 10.2.)
code:
```
# If embeddings come from a different provider, make a second client:
embed_client = OpenAI(
    api_key=os.environ.get("NIM_API_KEY", os.environ["GROQ_API_KEY"]),
    base_url=os.environ.get("NIM_BASE_URL", os.environ["GROQ_BASE_URL"]),
)
EMBED_MODEL = os.environ["EMBED_MODEL"]

def embed(text):
    resp = embed_client.embeddings.create(model=EMBED_MODEL, input=text)
    return resp.data[0].embedding
```

```

```
verify: Calling embed("hello") returns a long list of floats. Print len(embed("hello")) to see the vector's dimension (often several hundred or a few thousand numbers).

## BUILD_STEP
goal: Measure closeness with cosine similarity.
why: "How similar in meaning?" becomes "how close are the two vectors?" — a value near 1 means nearly the same meaning. (Learned in Phase 9, Ch 10, section 10.3.)
code:
```
import math

def cosine(a, b):
    dot = sum(x*y for x, y in zip(a, b))
    na = math.sqrt(sum(x*x for x in a))
    nb = math.sqrt(sum(y*y for y in b))
    return dot / (na * nb)
```
windows:
```
python atlas.py
```
ubuntu:
```
python3 atlas.py
```
verify: cosine(embed("reset my password"), embed("recover my login credentials")) is high (close to 1), while cosine(embed("reset my password"), embed("capital of France")) is much lower. Meaning, not words, drives the score.
reference: Phase 9, Ch 10

## BUILD_STEP
goal: Build a tiny in-memory semantic search over a handful of texts.
why: This is semantic search in miniature: embed everything ahead of time, embed the question at query time, return the closest. (Learned in Phase 9, Ch 10, section 10.4.)
code:
```
DOCS = [
    "To reset your password, click 'Forgot password' on the login page.",
    "Our office hours are 9am to 5pm, Monday to Friday.",
    "Refunds are processed within 5 business days.",
]
DOC_VECTORS = [(d, embed(d)) for d in DOCS]  # done once, ahead of time

def search(query, k=1):
    qv = embed(query)
    scored = [(cosine(qv, dv), d) for d, dv in DOC_VECTORS]
    scored.sort(reverse=True)
    return [d for _, d in scored[:k]]

print(search("I forgot my login credentials"))
```

verify: The query "I forgot my login credentials" returns the PASSWORD RESET document — even though they share almost no words. That is a match on meaning, the leap beyond keyword search.
troubleshoot: If results look random, confirm you use the SAME embed() model for both the docs and the query — vectors from different models cannot be compared.
reference: Phase 9, Ch 10
