## BUILD_STEP
goal: Install a lightweight agent framework (Strands Agents).
why: Strands is close to this book's philosophy — an agent is a model plus tools plus a prompt in a loop — and it is model-agnostic. You will see it does exactly what your raw loop does. (Learned in Phase 9, Ch 12, section 12.3.)
windows:
```
pip install strands-agents
```
ubuntu:
```
pip install strands-agents
```
verify: The framework installs without error. Run `pip list` and confirm it appears. (If you prefer LangGraph or the OpenAI Agents toolkit, the mapping is the same — only names differ.)
troubleshoot: If the package name has changed, search its current docs. The point is the CONCEPT: adopt a framework only when it saves more than it costs.
reference: Phase 9, Ch 12

## BUILD_STEP
goal: Rebuild the weather-style agent with the framework, in a new file atlas_fw.py.
why: Declaring a tool is Chapter 6's description; "instructions" is Chapter 4's system prompt; running the agent is Chapter 7's loop. Nothing is conceptually new. (Learned in Phase 9, Ch 12, section 12.5.)
code:
```
# atlas_fw.py — framework version (illustrative; adapt to the library's current API)
from strands import Agent, tool

@tool
def get_word_count(text: str) -> dict:
    """Count the words in a piece of text."""
    return {"word_count": len(text.split())}

agent = Agent(
    system_prompt="You are ATLAS. Use tools when they help; do not guess.",
    tools=[get_word_count],
)
print(agent("How many words are in: the quick brown fox jumps?"))
```
windows:
```
python atlas_fw.py
```
ubuntu:
```
python3 atlas_fw.py
```
verify: The framework version returns the same correct word count (6) as your hand-built loop — with retries, tracing, and memory handled "for free." Fewer lines; identical concepts.
troubleshoot: Configure the framework to use your OpenAI-compatible provider (Groq/NIM) via its model settings, so you keep your free stack. Consult the library's current model-config docs.
reference: Phase 9, Ch 12
