## BUILD_STEP
goal: Load and CHUNK the documents. Add chunking to atlas.py.
why: Chunking is the underrated make-or-break step — split at natural boundaries, keep chunks a few hundred words, with a little overlap. (Learned in Phase 9, Ch 11, section 11.3.)
code:
```
import glob

def load_docs(folder="docs"):
    texts = []
    for path in glob.glob(f"{folder}/*.txt"):
        texts.append((path, open(path, encoding="utf-8").read()))
    return texts

def chunk(text, size=800, overlap=100):
    # split on blank lines first (respect structure), then pack to ~size chars
    paras = [p.strip() for p in text.split("\n\n") if p.strip()]
    chunks, cur = [], ""
    for p in paras:
        if len(cur) + len(p) > size and cur:
            chunks.append(cur)
            cur = cur[-overlap:] + " " + p   # carry a little overlap
        else:
            cur = (cur + " " + p).strip()
    if cur:
        chunks.append(cur)
    return chunks
```
verify: Running chunk() on your notes produces a list of coherent passages, each a few hundred characters, split at paragraph boundaries with slight overlap.
troubleshoot: If chunks are one giant blob, your file has no blank lines between paragraphs — add them, or lower the size. Too-big chunks dilute meaning; too-small chunks lose context.
reference: Phase 9, Ch 11

## BUILD_STEP
goal: Build the index — chunk, embed, and store each chunk with its source metadata.
why: This is Phase One of RAG (indexing), done once and re-run whenever documents change. Keep metadata so you can cite the source. (Learned in Phase 9, Ch 11, section 11.2.)
code:
```
INDEX = []  # list of dicts: {"text":..., "source":..., "vector":...}

def build_index(folder="docs"):
    INDEX.clear()
    for path, text in load_docs(folder):
        for c in chunk(text):
            INDEX.append({"text": c, "source": path, "vector": embed(c)})
    print(f"indexed {len(INDEX)} chunks from {folder}")

build_index()
```

python atlas.py
```

```
verify: It prints how many chunks were indexed. Each entry carries its text, its source file (metadata for citations), and its meaning-vector.

## BUILD_STEP
goal: Retrieve the most relevant chunks for a question.

def retrieve(question, k=3):
    qv = embed(question)
    scored = [(cosine(qv, item["vector"]), item) for item in INDEX]
    scored.sort(key=lambda x: x[0], reverse=True)
    return [item for _, item in scored[:k]]

## BUILD_STEP
goal: Augment and generate — answer USING ONLY the retrieved context, with a citation.
why: The grounding instruction turns a hallucination-prone model into a checkable one: use only the context, admit ignorance, cite the source. (Learned in Phase 9, Ch 11, section 11.4.)
code:
```
def rag_answer(question, k=3):
    chunks = retrieve(question, k)
    context = "\n\n".join(f"[{i+1}] (source: {c['source']})\n{c['text']}"
                          for i, c in enumerate(chunks))
    return ask([
        {"role": "system", "content":
         "Answer the question using ONLY the context below. "
         "If the answer is not in the context, say you don't know. "
         "Cite the [number] of the piece you used."},
        {"role": "user", "content": f"Context:\n{context}\n\nQuestion: {question}"},
    ])

print(rag_answer("<ask something answerable from your docs>"))
```
