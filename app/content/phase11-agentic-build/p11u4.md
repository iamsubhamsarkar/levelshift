## BUILD_STEP
goal: Wrap retrieval as a tool the agent can call.
why: In basic RAG, retrieval is a fixed pipeline. In agentic RAG, retrieval becomes a TOOL the agent chooses to use — deciding WHEN and WHAT to search. (Learned in Phase 9, Ch 11, section 11.6.)
code:
```
def search_docs(query: str) -> dict:
    """Search the user's documents for relevant passages."""
    chunks = retrieve(query, k=3)
    return {"results": [{"source": c["source"], "text": c["text"]} for c in chunks]}

TOOL_IMPLS["search_docs"] = search_docs
TOOLS.append({
    "type": "function",
    "function": {
        "name": "search_docs",
        "description": "Search the user's own documents for relevant passages. "
                       "Use this whenever the question is about the user's notes, handbook, or files.",
        "parameters": {
            "type": "object",
            "properties": {"query": {"type": "string", "description": "What to search for."}},
            "required": ["query"],
        },
    },
})
```
verify: The file saves. ATLAS now has search_docs alongside its other tools — retrieval is a capability the agent can reach for, not a fixed step.
reference: Phase 9, Ch 11

## BUILD_STEP
goal: Ask a question that makes the agent CHOOSE to retrieve.
why: Agentic RAG shines on questions where the agent decides retrieval is needed — versus answering directly. (Learned in Phase 9, Ch 11, section 11.6.)

```
if __name__ == "__main__":
    print(run_agent("According to my notes, what are the office hours?"))
```

verify: In the trace you see ATLAS call search_docs, receive passages, then answer with a citation. Ask a general-knowledge question instead ("what is 2+2?") and it should answer WITHOUT retrieving — that judgment is the point of agentic RAG.
troubleshoot: If it retrieves for everything, tighten the tool description ("only for the user's own documents"). If it never retrieves, make the description clearer about when to use it.
reference: Phase 9, Ch 11

## BUILD_STEP
goal: Enable MULTI-HOP retrieval — search, read, then search again with a refined query.
why: The loop lets the agent realize it needs more, and search again — something a fixed pipeline cannot do. (Learned in Phase 9, Ch 11, section 11.6, and Ch 7.)
code:
```
if __name__ == "__main__":
    print(run_agent(
        "Find in my notes what product we discussed, then search for that product's refund policy."
    ))
```
windows:
```
python atlas.py
```
ubuntu:
```
python3 atlas.py
```
verify: The trace shows TWO search_docs calls — the second query built from what the first returned. That is multi-hop retrieval, the loop of Chapter 7 applied to search.
troubleshoot: If it stops after one search, remind it in the goal that it may search more than once. Your step limit (Unit 5) still bounds the total work.
reference: Phase 9, Ch 7, Ch 11
