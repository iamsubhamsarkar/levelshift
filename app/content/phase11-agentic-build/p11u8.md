## BUILD_STEP
goal: Ask the multi-hop question and watch the full system work.
why: This is the phase capstone: the supervisor delegates research, which does multi-hop retrieval, and the answer is grounded and cited. (Learned in Phase 9, Ch 7, Ch 11, Ch 14.)
code:
```
if __name__ == "__main__":
    print(run_agent(
        "What is the deadline of our current project? "
        "First find the project's codename in my notes, then find that project's deadline."
    ))
```
windows:
```
python atlas.py
```
ubuntu:
```
python3 atlas.py
```
verify: ATLAS resolves it in two hops — first retrieving the codename (Falcon), then retrieving Falcon's deadline (March 15) — and answers with a citation. The trace shows more than one retrieval, driven by the loop.
troubleshoot: If it answers only the first hop, remind it in the goal to use the first result to search again. The step limit and global budget keep it safe if it over-searches.
reference: Phase 9, Ch 7, Ch 11, Ch 14
