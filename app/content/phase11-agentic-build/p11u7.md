## BUILD_STEP
goal: Build the specialist as a function that runs its OWN small loop — then expose it as a tool.
why: The cleanest multi-agent design: a sub-agent is just something the coordinator can CALL, exactly like a tool. Coordination stays explicit. (Learned in Phase 9, Ch 14, section 14.2.)
code:
```
def research_agent(question: str) -> dict:
    """A focused sub-agent: searches the user's docs and returns a grounded summary."""
    chunks = retrieve(question, k=3)
    context = "\n\n".join(f"(source: {c['source']}) {c['text']}" for c in chunks)
    summary = ask([
        {"role": "system", "content":
         "You are a research specialist. Summarize an answer to the question using ONLY the context. "
         "Return 2-3 sentences and say if the context is insufficient."},
        {"role": "user", "content": f"Context:\n{context}\n\nQuestion: {question}"},
    ])
    return {"summary": summary, "sources": list({c["source"] for c in chunks})}

TOOL_IMPLS["research"] = research_agent
```
verify: The file saves. research_agent runs its own retrieval + reasoning and returns a STRUCTURED contract ({"summary", "sources"}) — a validated hand-off, not free-form chatter.
reference: Phase 9, Ch 14

## BUILD_STEP
goal: Register the sub-agent as a tool on the supervisor.
why: To the supervisor, "research" looks like any other tool — but behind it sits a whole specialist agent. This is the supervisor (hub-and-spoke) topology, the recommended default. (Learned in Phase 9, Ch 14, section 14.3.)
code:
```
TOOLS.append({
    "type": "function",
    "function": {
        "name": "research",
        "description": "Delegate a research question to a specialist that searches the user's "
                       "documents and returns a grounded summary with sources. Use for questions "
                       "that require reading the user's files.",
        "parameters": {
            "type": "object",
            "properties": {"question": {"type": "string", "description": "The research question."}},
            "required": ["question"],
        },
    },
})
```
verify: The file saves. The supervisor (your run_agent) now has a "research" tool. Workers do not talk to each other — only to the supervisor.
reference: Phase 9, Ch 14
