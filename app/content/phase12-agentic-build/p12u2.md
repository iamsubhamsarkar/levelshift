## BUILD_STEP
goal: Add a trace recorder to atlas.py.
why: You cannot debug an agent from a stack trace — you must capture the full trajectory: every model call, tool call, and observation. (Learned in Phase 9, Ch 16, section 16.1.)
code:
```
import time, uuid

class Trace:
    def __init__(self):
        self.trace_id = str(uuid.uuid4())[:8]
        self.spans = []

    def span(self, kind, **data):
        self.spans.append({"kind": kind, "t": round(time.time(), 3), **data})

    def summary(self):
        tools = [s["name"] for s in self.spans if s["kind"] == "tool"]
        return {"trace_id": self.trace_id, "steps": len(self.spans), "tools_used": tools}
```
verify: The file saves. A Trace holds an id and a list of spans — the same trace-and-span structure you know from microservice tracing.
reference: Phase 9, Ch 16

## BUILD_STEP
goal: Run a task and inspect the recorded trajectory.
why: Inspecting a real trajectory is how you diagnose wrong tool choices, bad arguments, loops, and drift. (Learned in Phase 9, Ch 16, section 16.2.)
code:
```
if __name__ == "__main__":
    answer, trace = run_agent("Research our refund policy, then count its words.")
    print(answer)
    print("TRACE:", trace.summary())
    for s in trace.spans:
        print(" ", s)
```
