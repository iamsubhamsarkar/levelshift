## BUILD_STEP
goal: Write a rule-based scorer for the classifier.
why: When output is a fixed choice, you CAN assert precisely — this is ordinary assertion, the cheapest and most reliable scorer. (Learned in Phase 9, Ch 15, section 15.4.)
code:
```
from atlas import classify_safe

def score_case(case):
    try:
        result = classify_safe(case["input"])
        return result.severity == case["expect_severity"]
    except Exception:
        return False
```
verify: score_case returns True/False for a single case by comparing the model's severity to the expected one. Structured output (Phase 10) made this a plain assertion.
reference: Phase 9, Ch 15

## BUILD_STEP
goal: Run each case MULTIPLE times and measure a pass rate.
why: Because agents are non-deterministic, "it worked once" proves nothing. A pass rate across repeated runs reveals flakiness. (Learned in Phase 9, Ch 15, section 15.6.)
code:
```
def pass_rate(case, runs=5):
    passes = sum(1 for _ in range(runs) if score_case(case))
    return passes / runs

if __name__ == "__main__":
    for c in CASES:
        rate = pass_rate(c)
        flag = "OK" if rate == 1.0 else ("FLAKY" if rate >= 0.5 else "FAILING")
        print(f"{rate:.0%}  {flag}  {c['input'][:40]}")
```
windows:
```
python evals.py
```
ubuntu:
```
python3 evals.py
```
verify: Each case prints a pass rate over 5 runs. A case at 100% is robust; one at 60% is FLAKY and needs a tighter prompt, lower temperature, or better constraints. You are now quantifying reliability, not guessing.
troubleshoot: If everything is flaky, confirm temperature is 0 for classification and the allowed severities are named clearly in the prompt. Flakiness is a signal to tighten the spec.
reference: Phase 9, Ch 15

## BUILD_STEP
goal: Add a threshold gate and print an overall verdict.
why: A threshold is your CI gate — block a change if quality drops below the bar. (Learned in Phase 9, Ch 15, section 15.8.)
code:
```
def suite_passes(threshold=0.8):
    rates = [pass_rate(c) for c in CASES]
    overall = sum(rates) / len(rates)
    print(f"suite average: {overall:.0%} (threshold {threshold:.0%})")
    return overall >= threshold

if __name__ == "__main__":
    ok = suite_passes()
    print("GATE:", "PASS" if ok else "FAIL")
```
windows:
```
python evals.py
```
ubuntu:
```
python3 evals.py
```
verify: The suite prints an average and a PASS/FAIL gate. Now you can change a prompt or swap Groq to NIM, re-run, and see with EVIDENCE whether quality held.
reference: Phase 9, Ch 15
