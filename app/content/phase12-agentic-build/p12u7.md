## BUILD_STEP
goal: Run the EXACT same build on your OTHER operating system.
why: Cross-platform is a first-class goal — the venv-based build runs on both Windows and Ubuntu 24.04 with only the activation command differing. (Learned across all build phases.)
windows:
```
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python atlas.py
```
ubuntu:
```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 atlas.py
```
verify: ATLAS produces the same behavior on the second OS. If you have both machines, confirm it there; if not, confirm the commands match what you have been using and that a requirements.txt captures your dependencies.
troubleshoot: If a dependency is missing on the second OS, run `pip freeze > requirements.txt` on the working machine and install from it on the other. That file is your portable dependency contract.
reference: All build phases
